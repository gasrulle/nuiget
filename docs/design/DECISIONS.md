# Design decisions

Every decision of the UX initiative: the owner's picks between alternatives (one row per `AskUserQuestion` round,
with the alternatives' artifact URLs, the pick and the trade-off) and the design-advisor's rulings under the
closest-to-the-workbench rule. A replacement session never re-asks a recorded decision. ADRs record the ones that
bind implementation; this file is the chronological index.
