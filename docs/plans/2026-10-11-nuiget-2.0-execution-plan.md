## 2. Execution model for Opus 5.5 + Fable advisor

### 2.1 Unit of work
One work item = one session = one PR, ≤ 1 session-day. Each item states inputs, outputs, gate command with
expected result, and stop-and-ask triggers.

**"The item's files"** = the sources it names + their `*.test.ts(x)` + their `__fixtures__/**` + the directory's
`STATUS.md` + `CHANGELOG.md` `[Unreleased]` + the ARCHITECTURE.md 2.0 section + `docs/plans/STATUS.md` + any config
file the item names. Anything else is a stop-and-ask. Tests the item names by line or title may be rewritten without
asking; the STATUS note lists each.

### 2.2 Session ritual (fixed order)
1. **Bootstrap:** `node --version && npm --version && dotnet --list-sdks` → v24.21.0 / 11.19.0 / 10.0.401 (8.0.425 may also be listed). If anything is missing, stop and report; never download toolchains.
2. **Orient:** `git status --short`, `git log --oneline -8`, this plan's item row. For a salvage item read the **quarry's** `STATUS.md`, verify it against the quarry tree, and write a fresh one in the target; for other items read the target directory's `STATUS.md` and verify its claims with `ls`/`grep`.
3. **Baseline gates before editing:** `npx tsc --noEmit` → 0; `npx eslint src` → 0 errors, 0 warnings; `npx vitest run` → green. Red before you touched anything → stop and ask.
4. **Do the item** within the item's files.
5. **Gates after editing**, in order: `npx tsc --noEmit` · `npx eslint src` · targeted `npx vitest run --project backend|frontend <dir>` · `npm test` · `npm run bench` · (host/service/esbuild) `npm run package:vsix` · (protocol) `npm run docs:protocol:check` · (packaging) `npm run check:vsix`. A gate command that triggers a permission prompt is run anyway and the prompt is noted; never substitute a different command.
6. **Docs duties:** CHANGELOG `## [Unreleased]` (Added: `**Headline** — text`; Fixed/Changed: headline only; breaking: `### Changed` `**Breaking:** …`); ARCHITECTURE.md only under `## 2.0 Architecture (in progress)`; copilot-instructions gotcha table only for new footguns; `.claude/` mirror when a `.github/` resource changes.
7. **Handoff note:** rewrite the directory's `STATUS.md` with the §2.5 template.
8. **Commit** via the `git-commit` skill; body cites item and finding IDs (`feat(core/ops): OperationQueue v2 (P2.1, ADR-003, Y2, Y3)`). Never commit red. Never end a turn with untracked source files: commit green, or move the WIP under `src/_wip/` (excluded from tsc/eslint/vitest/VSIX by P0.11) and say so.
9. **Report:** every gate run with its result; every gate skipped with the reason.

### 2.3 Advisor mechanism (verified against the Claude Code docs on 2026-10-11)

Facts: `/advisor` only sets `advisorModel`; the consultation is a server-side tool the main model calls at its own
discretion, cannot be forced, sees the full transcript but **has no file access**, and for the Opus 5.5 + Fable 5.1
pairing its reply is **not readable by the user**. Therefore:

| Layer | Mechanism | Used for |
|---|---|---|
| **L1 Explicit consultation (relied on)** | Repo subagent `.claude/agents/architecture-advisor.md` (mirror `.github/agents/`), frontmatter `model: fable` (documented alias for Fable 5.1), read-only tools. Invoked with the §2.4 brief. Answer **recorded verbatim in `STATUS.md`** before work continues. | Every stop-and-ask trigger; items marked ⚑ (consult before writing code); end-of-phase diff reviews. |
| **L2 Hard guardrails** | `PreToolUse` hooks (P0.5): deny Edit/Write to `src/protocol/**`, `src/core/contracts.ts`, `docs/adr/**` unless the sentinel file `.claude/.contract-change` exists (D6); deny delete/rename of `*.test.ts(x)`; deny adding `\.(only|skip)\(` exactly (`.skipIf(` with a platform/env predicate is allowed); deny `git commit --no-verify`, `git push --force`; deny `git commit` while the sentinel exists. Hook message names the L1 consultation required. | Expensive wrong calls become "cannot". |
| **L3 Ambient advisor** | Owner runs `/model claude-opus-5-5` then `/advisor claude-fable-5-1` in the implementing session. `CLAUDE.md` §"2.0 execution protocol": consult the advisor before substantive work, when an error recurs, before declaring an item done, before weakening any test. | Catching what nobody anticipated. Never relied on for a specific moment. |

**Universal stop-and-ask triggers:** a contract/ADR mismatch; a failing test you did not write; any wish to delete,
skip or weaken a test not named by the item; a type error outside the item's files; CLI/SDK behaviour differing from
the tracked probe fixtures; a `STATUS.md` claim contradicted by the tree; the gate still red after two fix attempts;
any change to `package.json` `contributes`; any temptation to stub a missing module so `tsc` passes.

### 2.4 Advisor brief template
```text
ITEM: <P#.# title>            GATE STATUS: <tsc/eslint/vitest results>
OBSERVED: <one paragraph; exact error text or behaviour>
FILES: <path:line ranges read>
CONTRACT/ADR IN PLAY: <ids and the sentence that seems violated>
OPTIONS I SEE: 1) … 2) … (do not pick)
QUESTION: <one sentence>
```
Reply pasted under `## Advisor decisions` in the directory's `STATUS.md` with date and item ID.

### 2.5 `STATUS.md` template (rewritten at every handoff)
```text
# STATUS — <dir>   commit <sha>   <ISO timestamp>
git status --short <dir>: <paste or "clean">
## Verified by running
<command> → <pasted summary line>   (one per gate; "SKIPPED: <reason>" must be literal)
## Done (tested)        ## Done (untested)        ## Not started
## Deviations from contract/ADR (file:line each)
## Advisor decisions (date, item, question, answer verbatim)
## Exact next step (one item ID)
```
A note without commit SHA and pasted gate output is invalid.

### 2.6 Fixture and evidence policy
No decision may cite a gitignored artefact (the quarry's `__fixtures__/.scratch` has 28). Probe captures are promoted
to tracked, redacted fixtures. SDK-dependent integration tests run behind `NUIGET_SDK_TESTS=1` (CI sets it; local
runs may skip and must say so). Tests may create and remove their own scratch directories via `__fixtures__/scratch.ts`;
they may never read a pre-existing capture that is not tracked.
