> 5. `Listbox` keys:
>    - Ctrl/Cmd+ArrowUp on any row (package, group, message, disabled): `onExitUp?.()` and the default prevented when the prop is given; never a row move. Ctrl/Cmd+ArrowDown: no row move, not handled.
>    - PageDown, no modifier: the active row becomes the last row whose end is within one client height of the scroller from the active row's start, at least one row on, clamped to the last row. PageUp is the mirror. Group and message rows count as rows; the selection does not change; scrolling is `moveTo`'s. A list that does not scroll itself (N88) therefore pages to its ends; if one of the nine is such a list, send me its test id.
>    - Type-ahead, only with `typeaheadLabel`: a key of one character other than Space, without Ctrl, Meta or Alt and not composing, joins a buffer; the active row moves to the next row whose label starts with the buffer, case-insensitive, searching from the row after the active one for a first character and from the active row for a longer buffer, wrapping; no match leaves the row. Rows whose label is `undefined` are skipped. Space keeps its bulk meaning.
