> - The plan row's criterion is Visual Studio's Consolidate tab; option 1 is its plain reading. Options 2 and 3 fail on shape: the Installed tree is grouped by project and a drift list by package, and a consolidation is not an update (it may lower a version) and does not belong under Update All.

> - The tab strip's overflow row (design-system.md §8) already covers a longer strip: badges leave below 250, then labels ellipsize.

Its spec keys `tab-bar`, `installed-tab`, `updates-tab` (main-installed-all.spec.json:105-141) come before the new tab, so their rects should not move.
> - Interaction model §5 already fixes a bulk write as an in-panel dialog listing packages and projects. `ConfirmDialog` with `groups` (as `src/webview/shared/updates/UpdateAllDialog.tsx`) writes `<id> <old> → <new>` under "In <project>:" with no new primitive.
> - `complete` is never true in the dense fixture: `allProjects.tsx:484` puts every unsupported project in `unread`, and `tools/Unsupported` is always there. The count and the captured states cannot be gated on it.
