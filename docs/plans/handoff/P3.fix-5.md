> WHY:
> - Centring a badge in a row is row anatomy, not a badge size. `DS-HEIGHT-10` is hard on main and sidebar, so a pending clause inside it would mix statuses in one id; `DS-ROW-7` is the next free id (no hit for `DS-ROW-7` in `docs` or `src`).
