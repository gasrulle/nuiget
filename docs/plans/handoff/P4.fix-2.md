## Deviations from contract/ADR/decision

Deviations from the ruling's DO list, each from a local reading:

- `Developer: Reload Webviews` runs before case (1) for both views, not only for nUIget, so the two go through the same
  steps (WHY, second bullet). For the Extensions view it changes nothing the probe reads.
- The project file opens through Go to File (the palette without `>`, the pick labelled `TestProject.csproj`), not
  `VSBrowser.instance.openResources`: on the first local run `openResources` failed for this file in every case
  (`Failed to open resource(s) in the editor`).
- The nUIget focus-command lookup matches `/nuiget/i` and `/focus/i`, the Extensions lookup's two-pattern form: the local
  listing also shows `View: Show nUIget` and `nUIget: Clear NuGet HTTP Cache`, and another ranking would run one of them.
- The probe starts no case after 180 s of its 300 s budget and prints `not readable (the probe's budget is spent)`
  instead (a case can take about 80 s at worst). On the first local run the probe reached its timeout while still running; Mocha moved on, the probe's open
  editor intercepted the theme pass's clicks and five `theme.ui.test.ts` cases went red. The second run, with Go to File,
  took 86.9 s and all 23 cases passed.
- The lines go through `console.warn`: the test files' lint admits `warn` and `error` only.
- Each line adds `webview <bool> (in side bar <bool>)`. A webview view's `iframe.webview` is not inside `.part.sidebar`
  (it is placed over the part), so the ruling's "an `iframe.webview` inside `.part.sidebar`" reads `false` for nUIget
  even when its frame has the focus. The verdict token reads the frame for nUIget, as ruled, so it does not depend on
  this field.
- The editor part's selector is `.part.editor`; checked locally (`editor true` on the toggle case's Extensions lines).
- Case (4), window start, is not read in this push: the only form is `Developer: Reload Window`, which may end the Linux
  driver session, and then `theme.ui.test.ts` and the chained capture run go red (ruling WHY, fifth bullet). A host
  change that acts at resolve time cannot be ruled without that reading.
