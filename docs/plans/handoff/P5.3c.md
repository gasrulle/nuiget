> DECISION:

> - Item 5: the select is disabled while versions load with no list (`DetailsPane.tsx:208`), so the user cannot have chosen before the first answer. "Unless the user chose" only matters for later answers, hence "once".
> - Golden: `main-consolidate.dark-modern.1200.png` shows `details-empty` beside two rows with no row current. Nothing in this ruling changes that cell.
